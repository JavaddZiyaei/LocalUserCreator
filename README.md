# 👤 Windows Local User Creator

ابزار گرافیکی ویندوز برای **ساخت گروهی کاربران محلی (Local Users)** با رابط کاربری مدرن و ساده.

این برنامه با استفاده از **Python** و **CustomTkinter** ساخته شده و امکان ایجاد چندین حساب کاربری محلی را به‌صورت هم‌زمان فراهم می‌کند.

## ✨ امکانات

* 👤 ساخت گروهی کاربران محلی ویندوز
* 🔢 امکان ایجاد تا **۲۰۰ کاربر** در هر بار اجرا
* 🖥️ نمایش پیش‌نمایش کاربران قبل از ساخت
* 📊 نمایش نوار پیشرفت هنگام ساخت کاربران
* ✅ نمایش وضعیت موفق یا ناموفق بودن ایجاد هر کاربر
* 🔐 تولید نام کاربری و رمز عبور به‌صورت خودکار
* 📄 ذخیره اطلاعات کاربران ساخته‌شده در فایل متنی
* 🌐 پشتیبانی از زبان فارسی و انگلیسی
* 🌙 رابط کاربری Dark Mode
* 🔄 امکان تغییر زبان از داخل برنامه
* ⚡ اجرای عملیات ساخت در Thread جداگانه برای جلوگیری از هنگ کردن رابط کاربری

## 🖥️ پیش‌نیازها

* Windows 10 یا Windows 11
* Python نسخه **3.10 یا بالاتر**
* دسترسی Administrator
* اتصال به اینترنت برای نصب وابستگی‌ها

> ⚠️ برنامه فقط روی سیستم‌عامل Windows قابل اجرا است.

## 📦 نصب

ابتدا مخزن را Clone کنید:

```bash
git clone https://github.com/USERNAME/Windows-Local-User-Creator.git
```

وارد پوشه پروژه شوید:

```bash
cd Windows-Local-User-Creator
```

سپس وابستگی موردنیاز را نصب کنید:

```bash
pip install customtkinter
```

## ▶️ اجرای برنامه

برای اجرای برنامه:

```bash
python main.py
```

> نام فایل اصلی پروژه را در صورت متفاوت بودن با `main.py` جایگزین کنید.

## 👤 نحوه استفاده

1. برنامه را اجرا کنید.
2. تعداد کاربران موردنظر را وارد کنید.
3. لیست کاربران در بخش پیش‌نمایش نمایش داده می‌شود.
4. روی دکمه **ایجاد کاربران** کلیک کنید.
5. درخواست تأیید را تأیید کنید.
6. برنامه کاربران را به‌صورت خودکار ایجاد می‌کند.
7. وضعیت ایجاد هر کاربر و درصد پیشرفت نمایش داده می‌شود.
8. اطلاعات کاربران موفق در فایل زیر ذخیره می‌شود:

```text
C:\LocalUsers_Credentials.txt
```

## 🔑 ساختار کاربران

نام کاربران به‌صورت خودکار تولید می‌شود:

```text
pc01
pc02
pc03
...
pc200
```

رمز عبور نیز بر اساس شماره کاربر ایجاد می‌شود:

```text
pc@1
pc@2
pc@3
...
pc@200
```

## 📄 فایل اطلاعات کاربران

پس از ایجاد کاربران، اطلاعات حساب‌های موفق در فایل زیر ذخیره می‌شود:

```text
C:\LocalUsers_Credentials.txt
```

این فایل شامل موارد زیر است:

* تاریخ ایجاد
* نام کاربری
* رمز عبور
* تعداد کل کاربران ساخته‌شده

## 🌐 زبان برنامه

برنامه در حال حاضر از دو زبان پشتیبانی می‌کند:

* 🇮🇷 فارسی
* 🇬🇧 انگلیسی

زبان برنامه از طریق دکمه تغییر زبان در رابط کاربری قابل تغییر است.

## ⚙️ محدودیت

حداکثر تعداد کاربران قابل ایجاد در هر بار اجرا:

```text
200 Users
```

همچنین اجرای برنامه روی سیستم‌عامل‌های غیر از Windows پشتیبانی نمی‌شود.

## 🛠️ تکنولوژی‌های استفاده‌شده

* Python
* CustomTkinter
* Tkinter
* Windows `net user`
* Threading

## ⚠️ نکات مهم

این برنامه برای ایجاد حساب‌های **Local User** در ویندوز طراحی شده است.

برای ایجاد کاربران، برنامه از دستور داخلی ویندوز `net user` استفاده می‌کند؛ بنابراین ممکن است برای اجرای صحیح عملیات به دسترسی Administrator نیاز داشته باشد.

همچنین فایل `C:\LocalUsers_Credentials.txt` شامل اطلاعات ورود کاربران است. این فایل را در اختیار افراد غیرمجاز قرار ندهید.
