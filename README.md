# 👤 Windows Local User Creator

ابزار گرافیکی ویندوز برای **ساخت گروهی کاربران محلی (Local Users)** با رابط کاربری مدرن و ساده.

این برنامه به‌صورت فایل اجرایی آماده شده و برای استفاده نیازی به نصب Python یا کتابخانه‌های جانبی ندارد.

## ✨ امکانات

* 👤 ساخت گروهی کاربران محلی ویندوز
* 🔢 امکان ایجاد تا **۲۰۰ کاربر** در هر بار اجرا
* 🖥️ نمایش پیش‌نمایش کاربران قبل از ساخت
* 📊 نمایش نوار پیشرفت عملیات
* ✅ نمایش وضعیت کاربران موفق و ناموفق
* 🔐 تولید خودکار نام کاربری و رمز عبور
* 📄 ذخیره اطلاعات کاربران ساخته‌شده در فایل متنی
* 🌐 پشتیبانی از فارسی و انگلیسی
* 🌙 رابط کاربری Dark Mode
* 🔄 تغییر زبان از داخل برنامه

## 🚀 نحوه استفاده

1. فایل اجرایی برنامه را از بخش **Releases** دانلود کنید.
2. برنامه را اجرا کنید.
3. تعداد کاربران موردنظر را وارد کنید.
4. لیست کاربران را در بخش پیش‌نمایش مشاهده کنید.
5. روی **ایجاد کاربران** کلیک کنید.
6. درخواست تأیید را تأیید کنید.
7. منتظر بمانید تا فرآیند ساخت کاربران کامل شود.

> ⚠️ برای ایجاد کاربران محلی، اجرای برنامه با دسترسی **Administrator** توصیه می‌شود.

## 👤 ساختار کاربران

نام کاربران به‌صورت خودکار ایجاد می‌شود:

```text
pc01
pc02
pc03
...
pc200
```

رمز عبور کاربران نیز به‌صورت خودکار تولید می‌شود:

```text
pc@1
pc@2
pc@3
...
pc@200
```

## 📄 فایل اطلاعات کاربران

پس از ساخت کاربران، اطلاعات حساب‌های موفق در مسیر زیر ذخیره می‌شود:

```text
C:\LocalUsers_Credentials.txt
```

این فایل شامل:

* تاریخ ایجاد
* نام کاربری
* رمز عبور
* تعداد کاربران ساخته‌شده

## 🌐 زبان‌ها

برنامه از دو زبان پشتیبانی می‌کند:

* 🇮🇷 فارسی
* 🇬🇧 English

برای تغییر زبان، از دکمه زبان داخل برنامه استفاده کنید.

## ⚙️ محدودیت

* حداکثر **۲۰۰ کاربر** در هر عملیات
* فقط قابل اجرا روی **Windows 10 و Windows 11**

## ⚠️ نکات امنیتی

فایل `C:\LocalUsers_Credentials.txt` شامل نام کاربری و رمز عبور حساب‌های ایجادشده است.

این فایل را در اختیار افراد غیرمجاز قرار ندهید.



## 🛠️ تکنولوژی
